How OpenSpiel Works

OpenSpiel is Google's collection of 119+ game environments with a shared API. This page lets you play any of them against a Monte Carlo Tree Search (MCTS) AI.

Game Selection

Search or scroll to find a game. Some games have parameters (board size, scoring type) — configure them before clicking the game name.

Playing

After selecting a game, the page starts a new instance. Click an action button from the list below the board to make a move. The AI responds automatically.

If the game has a grid (Tic-Tac-Toe, Connect Four, Breakthrough, Othello, Go, etc.), a board preview shows moves as colored dots.

Modes

  • Human vs AI — You play as Player 0, MCTS AI plays as Player 1.
  • AI vs AI (MCTS) — Two MCTS AIs play each other (spectator mode).
  • AI vs AI (Random) — MCTS vs random-rollout AI.

MCTS (Monte Carlo Tree Search)

The AI simulates thousands of random playouts from each possible move, then picks the one with the best win rate. More simulations = stronger play (default: 100, settable via the simulations parameter in the request).

Troubleshooting

If you get "0 of 0 games" or connection errors, the OpenSpiel server on port 11216 isn't running. Start it via start.ps1 or the "Start All Engines" button on the MCP dashboard.

What is OpenSpiel?

OpenSpiel is a research framework from Google DeepMind (2019) that provides 119+ game environments with a shared API. It's designed for reinforcement learning research: training agents that can play many different games without game-specific code.

Games range from perfect-information (chess, Go, tic-tac-toe) to imperfect-information (poker, Bridge, Liar's Dice) to cooperative (Hanabi). It includes built-in algorithms: MCTS, Minimax, CFR, NFSP, and AlphaZero-style training.

Paper: Lanctot et al., "OpenSpiel: A Framework for Reinforcement Learning in Games" — arXiv:1908.09453

This is likely the only browser UI for OpenSpiel. Most researchers interact with it via Python scripts. See REFERENCES.md for the full bibliography.
