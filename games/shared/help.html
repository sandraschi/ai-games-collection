🖥️ Server/PC Setup SERVER

These steps are done on your PC/Mac/Linux server machine

🚀 Starting the Server

Option 1: Simple Start (Recommended)

  1. Open PowerShell/Terminal in the ai-games-collection folder
  2. Run: .\START_EVERYTHING.ps1 (Windows) or ./start-everything.sh (Linux/Mac)
  3. Browser opens automatically at http://localhost:10986

Option 2: Docker

  1. Make sure Docker Desktop is running
  2. Run: docker compose up -d
  3. Open http://localhost:10986

🤖 AI Backend Servers

The server automatically starts these AI engines:

  • Stockfish (Chess) - Port 11211
  • YaneuraOu (Shogi) - Port 11212
  • KataGo (Go) - Port 11213
  • OpenSpiel (119 games) - Port 11216
  • Web app (Main site) - Port 10986

Users don't need to know about these - they work automatically!

🌐 Multiplayer Setup SERVER

Optional server configuration for online multiplayer

⚠️ Firebase Configuration (Optional)

Multiplayer requires Firebase setup. This is completely optional - all games work perfectly without it!

Server Setup Steps:

  1. Create Firebase project at console.firebase.google.com
  2. Enable Authentication (Email/Password)
  3. Enable Realtime Database
  4. Copy config to firebase-config.js
  5. See FIREBASE_SETUP_GUIDE.md for details

Without Firebase: All games work in single-player and local multiplayer!

⚙️ Server Troubleshooting SERVER

Fixing server-side issues (PC/Mac/Linux)

AI doesn't work in Chess/Shogi/Go

Make sure AI servers are running:

.\START_EVERYTHING.ps1 (Windows)
./start-everything.sh (Linux/Mac)

Or start manually:

python stockfish-server.py
python shogi-server.py
python go-server.py

Web server not responding

Start web server on port 9876:

python -m http.server 9876
python web-server.py (with AI)

Docker issues

Rebuild after code changes:

docker compose down
docker compose build
docker compose up -d

Text-to-speech issues

Install language packs:

Windows: Settings → Time & Language → Speech → Add voices

macOS: System Settings → Accessibility → Spoken Content

🎯 Game Tips & Tricks CLIENT

How to get the most out of each game (from any device)

♟️ Chess

• Click "Change Pieces" for different styles

• Check education center for openings

🧩 Crossword

🔧 Client Troubleshooting CLIENT

Issues you might encounter when playing from iPad, phone, or browser

Games not loading

Make sure you can access the server URL (usually ends in :9876)

  • Check if server is running (ask server owner)
  • Try refreshing the page
  • Clear browser cache if needed
  • Check internet connection

AI opponents not working

This usually means the server backend isn't running

  • Chess/Shogi/Go: Need server-side AI engines
  • Other games: Use client-side AI (slower)
  • Contact server admin to restart services
  • Check server status in Debug page

Touch controls not working

  • Make sure you're on a touch device (iPad/phone)
  • Try refreshing the page
  • Some games need keyboard for certain features
  • Use landscape mode for better controls

Audio not working

  • Check device volume and mute settings
  • Some browsers block autoplay audio
  • Click anywhere on the page first
  • Try a different browser

💡 Most issues are server-side! If games aren't working, the problem is usually on the PC/Mac running the server, not your device.
