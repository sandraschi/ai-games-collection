🌐 Multiplayer Help Guide

How to play games with friends - local network or worldwide

🎮 Multiplayer Overview

The games collection supports two multiplayer modes:

🏠 Local Network Mode

Best for: Home, office, same WiFi

Speed: Lightning fast

Setup: Minimal

Privacy: Completely private

🌍 Internet Mode (Firebase)

Best for: Worldwide play

Speed: Good with internet

Setup: Requires Firebase account

Privacy: Google servers

🖥️ Server Setup (PC/Mac/Linux)

You need to run the multiplayer server on your PC first.

🚀 Quick Start

  1. Open PowerShell/Terminal in the ai-games-collection folder
  2. Run: .\START_EVERYTHING.ps1
  3. The multiplayer server will start automatically on port 9877
  4. Verify: You should see "Multiplayer server started on port 9877"

🎯 Manual Server Start

If you need to start just the multiplayer server:

python multiplayer-server.py

⚠️ Important

The multiplayer server must be running for anyone to play multiplayer games. It's separate from the web server.

🏠 Local Network Multiplayer

Play with friends on the same network - WiFi OR Tailscale VPN!

Players can be in different cities (Cape Town ↔ Vienna) if connected via Tailscale!

🎯 How to Play Locally

  1. Make sure the multiplayer server is running on one PC
  2. All players must be on the same network (WiFi OR Tailscale VPN)
  3. On any device, go to: http://[server-ip]:9876/multiplayer.html
  4. Click "Local Network" mode
  5. Enter your name and connect
  6. Choose a game and start playing!

🔍 Finding Your Server IP

On Windows: Open Command Prompt and run ipconfig

On macOS/Linux: Run ifconfig or ip addr

Look for your local IP (usually starts with 192.168.x.x)

🌐 Playing from Different Locations with Tailscale VPN

Want to play with friends in different cities? Use Tailscale VPN!

  1. Install Tailscale on both PCs: tailscale.com/download
  2. Both players join the same Tailscale network (tailnet)
  3. Use the Tailscale IP address instead of local WiFi IP
  4. Find Tailscale IP: Run tailscale ip in terminal
  5. Access: http://[tailscale-ip]:9876/multiplayer.html

Example: Player in Cape Town and Vienna can play chess together!

✅ Advantages

  • ⚡ Super fast (no internet lag)
  • 🔒 Completely private
  • 🚫 No external services needed
  • 💰 Free
  • 🌍 Works worldwide with Tailscale VPN

🌍 Internet Multiplayer (Firebase)

Play with friends from anywhere in the world!

⚙️ Firebase Setup Required

This mode requires a Firebase account and configuration. It's more complex but allows worldwide play.

🔧 Firebase Setup (Server Admin)

  1. Go to Firebase Console
  2. Click "Create a project" (or use existing)
  3. Enable Authentication → Email/Password
  4. Enable Realtime Database
  5. Go to Project Settings → General → Your apps
  6. Copy the Firebase config object
  7. Create firebase-config.js in the games folder

📝 Firebase Config File

Create firebase-config.js:

// firebase-config.js const firebaseConfig = { apiKey: "your-api-key", authDomain: "your-project.firebaseapp.com", databaseURL: "https://your-project-default-rtdb.firebaseio.com", projectId: "your-project", storageBucket: "your-project.appspot.com", messagingSenderId: "123456789", appId: "1:123456789:web:abcdef123456" }; export { firebaseConfig };

🎮 How to Play Online

  1. Make sure Firebase is configured
  2. Go to the multiplayer page
  3. Click "Internet Play" mode
  4. Enter your name and connect
  5. Choose a game and start playing!

✅ Advantages

  • 🌍 Play from anywhere
  • 👥 Larger player base
  • 💾 Cloud saves
  • 📱 Cross-device play

♟️ Chess Real-time Sync

Chess uses a special high-performance sync engine:

  • FEN Sync: Only the board state string is sent, making it incredibly fast.
  • Turn Locking: The board automatically locks when it's your opponent's turn.
  • Auto-Flip: The board perspective matches your pieces (Black or White).

🔧 Troubleshooting

❌ "Server not connected"

# Check if server is running python multiplayer-server.py # Or use the all-in-one starter .\START_EVERYTHING.ps1

❌ Can't connect locally

  • Make sure all devices are on the same WiFi
  • Check firewall settings (allow port 9877)
  • Use the correct IP address
  • Try disabling VPN if active

❌ Firebase not working

  • Check firebase-config.js exists
  • Verify Firebase project is active
  • Check browser console for errors
  • Ensure Realtime Database rules allow access

🎮 Game-specific issues

  • AI not working: Make sure AI servers are running (ports 9543-9545)
  • Game crashes: Check browser console for JavaScript errors
  • Slow performance: Close other browser tabs
